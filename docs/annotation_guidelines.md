# MentalGuard 标注规范详细说明

> 版本：v1.0
> 更新日期：2026-08-03
> 适用数据集：MentalGuard

---

## 一、标注流程（五阶段层级构建流水线）

### Phase 1：多源数据采集

从 18 个权威信源采集候选健康谣言文本，信源分为三个层级：

- **Tier 1（政府/国际机构，9 个）**：国家卫健委、WHO、中国疾控中心、教育部等
- **Tier 2（学术团体，6 个）**：中华医学会、中国营养学会、中国心理学会等
- **Tier 3（社交媒体，3 个）**：新浪微博、抖音、科普中国视频库

采集方式：网页爬虫（requests + BeautifulSoup）、官方 API、手动检索。

### Phase 2：领域导向筛选

每个候选谣言按三维评分（满分 10 分）：

| 维度 | 权重 | 评定标准 |
|------|------|---------|
| 年龄关联度 | 40% | 是否直接涉及 12-18 岁青少年 |
| 传播触达度 | 35% | 在青少年高使用率平台的传播数据 |
| 健康危害性 | 25% | 误解导致的直接健康风险 |

### Phase 3：双源交叉验证

**核心规则**：每条谣言必须至少 2 个独立权威信源交叉验证。

- 优先使用 Tier 1（政府/国际机构）信源
- Tier 2（学术团体/期刊）作为补充验证
- 验证结果以结构化数组 `verified_sources` 记录
- 验证状态 `verification_status` 标记为 `verified` 或 `pending`

**实测结果**：100% 通过双源验证，其中73.8%含T1顶级信源。

### Phase 4：多模态知识扩展

为部分高影响力谣言添加多模态节点：

- **图像节点**：医学示意图、数据信息图、安全警示图
- **视频节点**：辟谣/科普视频（CCTV、B站等）
- **传播节点**：跨平台传播指标与情感分析

所有多模态节点均填充真实、可回溯打开的公开 URL。

### Phase 5：结构化标注与发布

按 12 字段标准标注，经专业人员二次审核后发布。

## 二、12 字段标注标准

### 2.1 字段定义

| # | 字段名 | 类型 | 必填 | 说明 |
|---|--------|------|------|------|
| 1 | `id` | string | ✅ | 唯一标识符，格式：类别前缀+3位序号 |
| 2 | `rumor_text` | string | ✅ | 谣言原始表述（一句话概括） |
| 3 | `truth_text` | string[] | ✅ | 科学真相（1-4条分点陈述） |
| 4 | `source` | string | ✅ | 证据来源原文 |
| 5 | `category` | string | ✅ | 所属类别中文名 |
| 6 | `category_key` | string | ✅ | 类别英文标识 |
| 7 | `severity` | enum | ✅ | 危险等级 |
| 8 | `keywords` | string[] | ✅ | 关键词标签（3-5个） |
| 9 | `platform` | string | ✅ | 主要传播平台 |
| 10 | `verified_sources` | object[] | ✅ | 交叉验证信源数组 |
| 11 | `verification_status` | enum | ✅ | 核验状态 |
| 12 | `source_tier` | enum | ✅ | 最高信源层级 |

### 2.2 ID 编码规则

| 类别 | 前缀 | 示例 |
|------|------|------|
| 青少年心理健康 | mh | mh001, mh002 |
| 校园食品安全 | fs | fs001 |
| 疫苗与健康 | vc | vc001 |
| 数字健康与近视防控 | dh | dh001 |
| 成瘾物质与功能饮品 | ss | ss001 |
| 饮食与身体形象 | bn | bn001 |
| 青春期皮肤健康 | dm | dm001 |
| 睡眠与昼夜节律 | sh | sh001 |
| 青春期生理健康 | sx | sx001 |

### 2.3 危险等级判定标准

| 等级 | 判定标准 | 典型案例 |
|------|---------|---------|
| `critical` | 可能导致死亡或永久残疾 | 危险三角区挤痘致颅内感染、抗抑郁药拒绝治疗致自杀 |
| `high` | 可能导致严重健康损害 | 电子烟成瘾、近视不矫正、节食致营养不良 |
| `medium` | 可能导致中度健康损害或经济损失 | 购买无效产品、错误护肤致皮肤屏障受损 |
| `low` | 主要为认知误区，健康危害有限 | BMI 审美误区、月经期间不能运动 |

### 2.4 `verified_sources` 结构化格式

```json
"verified_sources": [
  {
    "name": "教育部",
    "document": "近视防控20问答",
    "tier": "T1"
  },
  {
    "name": "中华医学会眼科学分会",
    "document": "近视防控专家共识",
    "tier": "T2"
  }
]
```

- `name`：信源机构名称（全称）
- `document`：具体文件/报告名称（可为空字符串）
- `tier`：信源层级（`T1` 或 `T2`）

## 三、多模态节点标注规范

### 3.1 图像节点

每个图像节点包含以下字段：

| 字段 | 说明 |
|------|------|
| `misconception_id` | 关联的谣言记录 ID |
| `type` | 图像类型：医学示意图 / 数据信息图 / 安全警示图 / 对比信息图 / 科研数据图 / 科普插图 |
| `desc` | 图像内容描述 |
| `source` | 图像来源机构 |
| `url` | 图像所在权威科普页面的 URL（可回溯打开） |
| `local_path` | 本地存储路径（相对路径） |
| `format` | 图像格式（jpg/png） |
| `status` | 验证状态（verified） |
| `url_type` | URL 类型分类 |
| `url_desc` | URL 内容描述 |

### 3.2 视频节点

| 字段 | 说明 |
|------|------|
| `misconception_id` | 关联的谣言记录 ID |
| `platform` | 视频所在平台（抖音/B站/小红书/CCTV） |
| `desc` | 视频内容描述 |
| `propagation` | 传播指标（播放量/点赞/弹幕等） |
| `url` | 视频 URL（指向辟谣/科普内容，非原始谣言视频） |
| `local_path` | 本地视频文件路径 |
| `keyframe_path` | 关键帧截图路径 |
| `status` | 验证状态 |
| `url_type` | URL 类型（counter_misinformation 等） |
| `url_desc` | URL 内容描述 |

### 3.3 传播节点

| 字段 | 说明 |
|------|------|
| `misconception_id` | 关联的谣言记录 ID |
| `platform` | 传播平台（微博/抖音/小红书/B站） |
| `metrics` | 传播指标对象（赞/转发/收藏/评论情感） |
| `source_url` | 传播来源 URL（研究论文/平台报告/辟谣平台） |
| `status` | 验证状态 |
| `url_type` | URL 类型 |
| `url_desc` | URL 内容描述 |

## 四、质量控制机制

### 4.1 双源交叉验证

- 每条记录必须 ≥2 个独立信源
- 信源独立性判定：不同机构/不同文件
- 结构化存储于 `verified_sources` 字段

### 4.2 危险等级审核

- critical/high 等级需医学背景人员审核
- 参照《中华医学会临床指南》和 WHO 安全性评估

### 4.3 URL 可访问性验证

- 使用 `scripts/verify_urls.py` 自动验证所有多模态节点 URL
- HTTP 200 视为可访问
- HTTP 412（反爬机制）在浏览器中可正常打开，视为有效
